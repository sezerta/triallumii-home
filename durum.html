Formüller ve eşikler
  • CPU % = Δ meşgul jiffies / Δ toplam jiffies × 100 — host /proc/stat, 5 sn'lik iki örnek arası.
  • RAM % = (MemTotal − MemAvailable) / MemTotal × 100 — host /proc/meminfo. Önbellek/tampon "kullanılabilir" sayılır.
  • Disk % = (blocks − bfree) / blocks × 100 — kök bölüm statvfs. Supabase verisi ayrı 50 GB imajda, kök diski dolduramaz.
  • Konteyner CPU % = Δcpu_usage / Δsystem_usage × çekirdek × 100 — Docker stats API. Toplam 8 çekirdek için üst sınır %800.
  • Konteyner RAM = memory_stats.usage − inactive_file — docker stats ile aynı.
  • Yük = 1/5/15 dakikalık ortalama; çekirdek sayısını (8) aşarsa kuyruklanma var.
  • Supabase probu /auth/v1/health yoluna gider; anahtar istemediği için 401 de "erişilebilir" sayılır.
  • Eşikler: disk ≥%80 uyarı, ≥%90 kritik · RAM ≥%85 uyarı · takas ≥%60 uyarı · CPU ≥%90 uyarı · sertifika ≤14 gün uyarı, ≤5 gün kritik · HTTP ≠ 200 kritik · konteyner çalışmıyor/sağlıksız kritik.
  • Ajan: stdlib Python, Docker soketi salt-okunur, host /proc ve kök salt-okunur bağlı. Yazma yetkisi yok.
